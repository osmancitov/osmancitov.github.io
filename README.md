# Lobby

Lobby es la sala de entrada de un edificio. La palabra inglesa viene del latín medieval *lobia*, un corredor cubierto: un lugar de paso antes de entrar a otras salas.

Esta es la entrada de una casa de archivos de texto, a la sombra de Unix. Las carpetas forman un árbol; cada sala puede tener sus propios cuartos. Los textos se pueden abrir, copiar y llevar a otra parte.

## Las salas

- **Destilería**: ensayos para reducir grandes textos sin perder lo que los hace vivir. Tiene dos cuartos: Protocolos y Bodega.
- **Taller**: cuadernos de estudio, pruebas, preguntas y trabajo en curso.
- **Journal**: el registro de los días, contado en prosa.

Tenga la bondad de ser liviano. Una página también ocupa tiempo y atención.
